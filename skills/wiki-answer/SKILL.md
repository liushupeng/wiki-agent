# 基于 Wiki 回答技能

回答基于知识库的问题时，使用此技能。

## 检索顺序

1. 使用 `search_notes` 或 `grep_notes` 召回候选，再通过 `wiki/` 来源前缀识别维护型页面。
2. 使用 `read_note` 阅读相关 Wiki 页面。
3. 若没有召回足够的 `wiki/` 证据，或证据已经过时、过于单薄，再检索原始来源。
4. 用户要求相邻概念或延伸阅读时，使用 `related_notes`。

## 回答规则

- 分别引用维护型 Wiki 页面与原始来源。
- 区分：
  - Wiki 中已经沉淀的结论；
  - 原始来源明确记载的事实；
  - Agent 的综合或推断。
- 证据足够后停止过度检索。
- 问题若产生可长期复用的综合结论，建议将其写回 Wiki。

## 建议输出结构

```text
结论：
<简短回答>

依据：
- Wiki：`wiki/concepts/example.md`
- 原始来源：`raw/example-source.md`

推断/不确定性：
<哪些内容属于推断或仍然缺失>

可沉淀内容：
<该回答是否应新增或更新 Wiki 页面>
```
