# 知识源分析技能

在索引真实且结构复杂的知识目录前，使用此技能。

## 目标

不要盲目索引所有内容。先理解目录结构，再产出可执行的来源策略：

```text
目录树
-> 领域分类
-> 来源类型
-> 忽略规则
-> 建议的 config/knowledge.sources.jsonc 变更
-> 首次小范围验证
```

## 输入

用户可能提供：

- `notes/` 下的一个路径。
- 知识库的简短描述。

## 审计清单

1. 识别顶层领域，例如财富、职业、计算机、项目、代码或数据。
2. 区分原始知识、代码项目、生成数据、缓存、图片和附件。
3. 标记应忽略的目录，例如 `__pycache__`、`node_modules`、`dist`、`build`、`.git`、`finalData`、生成的 CSV 目录或大型静态资源。
4. 建议优先索引的目录。
5. 建议哪些目录应维护为 Wiki，哪些只应提供检索。
6. 识别当前 loader 支持不佳的文件类型。
7. 提出最小化的 `config/knowledge.sources.jsonc` 更新建议。
8. 提出索引后应运行的 3–5 个真实验证问题。

## 输出结构

```markdown
## Source 审计摘要

## 领域分类

## 建议的知识源配置

## 忽略策略

## 首次验证范围

## 验证问题

## 风险与后续事项
```

## 规则

- 优先小范围首次验证，而非全量索引。
- 未从追踪记录、评测或失败案例观察到真实问题前，不建议新增代码。
- 让来源策略明确且可测试。
