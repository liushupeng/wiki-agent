# 笔记 RAG 技能

## 触发场景

用户问“我以前怎么想过这个问题”“某个概念在哪些笔记里出现过”“这篇笔记和哪些内容相关”“帮我根据笔记回答”等需要查本地笔记的问题。

## 方法

1. 先把用户问题改写成 1-3 个检索 query。
2. 调用 `search_notes` 获取 top-k 笔记片段。
3. 如果用户指定了某篇笔记，调用 `read_note` 获取更完整上下文。
4. 如果用户想扩展主题，调用 `related_notes` 找关联笔记。
5. 最终回答必须带来源引用，明确哪些结论来自笔记，哪些是你的推断。
6. 如果没有足够证据，直接说明缺口，不编造。

## 评估指标

- 引用是否命中正确笔记和标题路径。
- 回答是否覆盖问题里的实体和约束。
- 是否减少了不必要的全文读取和 token 消耗。
